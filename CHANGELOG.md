# Изменения

Формат: одна секция на версию, сверху — свежая. Версия репозитория хранится в файле `VERSION`;
её изменение в ветке `main` автоматически создаёт тег и релиз.

## 1.0.0 — 2026-09-22

Первый выпуск.

- Навигация по базе знаний: коллекции, структура коллекции, список и поиск документов, чтение.
- Документы: создание из чата по редакционному стандарту, правка и дописывание, публикация черновика,
  перемещение, архивация, удаление, выгрузка в Markdown.
- Ссылки для клиентов: выдача публичной ссылки (с вложенными документами или без), список выданных
  ссылок с числом просмотров и последним обращением, отзыв ссылки.
- Проверка содержимого перед отправкой: черновик — по внутренней планке, публикация и выдача ссылки —
  по клиентской. Реквизиты доступа, ключи, персональные данные и внутренняя кухня наружу не уходят.
- Запись требует явного `--yes`: без него команда печатает полный предпросмотр и ничего не меняет.
- Несколько инстансов Outline в одном конфиге, кэш справочников, единый разбор ошибок API.
